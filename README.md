# StowSync · 수출 컨테이너 통합 관제

기획서 시연과 캡처를 위한 **Streamlit 기능 데모**입니다. 올컨e·Port-i·TOS·기사 이력·GPS·터미널·화물은 모두 합성 데이터입니다. 실제 시스템 연결, 위치 수집, 메시지 발송 또는 장비 제어는 하지 않습니다.

## 실행

Python 3.12 권장.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

기본 주소: http://127.0.0.1:8501
코드 변경 후에는 실행 중인 서버를 재시작하세요. 파일 감시는 꺼져 있습니다.

## Streamlit Community Cloud

저장소 `hgehgehge-art/stowsync`, 브랜치 `main`, 진입점 `app.py`를 선택합니다. Python 3.12 환경을 권장합니다. `.venv`, `runtime/`, 비밀정보는 배포 소스에 포함하지 않습니다.

## 5분 시연

1. **통합 관제 → 배치 대안 검토**: 대안 2 또는 3을 선택하고 판단 사유와 함께 **선택한 배치 모의 승인**.
2. **변경·승인**: **현재 작업 완료까지 진행**으로 이동 완료 확인.
3. **기사 안내·학습**: 생성된 하차 안내에서 **기사 확인 모의 처리**. 현장 판단 학습 탭에서 **판단 기록으로 선호모델 학습** 후 반영 토글과 순위 비교 확인.
4. **트럭 ETA**: 운송 중인 화물을 선택. 동의를 끄거나 이력을 변경하고 **ETA 계산·배치 추천에 반영**. 이미 도착한 화물은 예측을 덮어쓰지 않음.
5. **2×2 예외 대응**: 현재 화물의 분류와 후보별 이동 횟수 확인. 좌측 시나리오에서 조기/지연·상위/하위 예시로 전환 가능.
6. **유휴시간 선작업**: 추천이 없으면 **선작업 시연 시나리오 열기**. 이 버튼은 현재 운영·기사 안내·알림을 초기화하며 판단 학습 기록은 유지. **선작업 모의 승인 → 변경·승인 → 완료**.
7. **데이터 연계**: T01 선박 일정 편차를 바꾸고 **선박 일정 변경·영향 반영**. **기사 안내·학습 → 변경 알림**에서 역할별 공유 확인.

위험물·환적은 CY 배치 추천의 컨테이너 선택에서 확인합니다. 위험물은 모의 전용 구역 후보만 나오며, 검토 체크 없이 승인할 수 없습니다. 크레인 가용·도착 상태에 따라 승인 버튼이 비활성화될 수 있습니다.

## 계산·안전·학습의 범위

- 2개 블록, 48개 물리 슬롯, 크레인 2대, 20ft 기준. 블록별 마지막 스택은 위험물 시연 전용 구역으로 일반 후보에서 제외합니다.
- 위험물 구역·혼적 제한은 단순한 **데모 규칙**입니다. 실제 IMDG 격리·터미널 안전 규정을 구현하거나 검증한 것이 아닙니다. 환적은 주 적용 대상인 수출 FCL 외의 예외 확인 시나리오입니다.
- ETA는 투명한 규칙 기반 합성 입력 결합입니다. **신뢰 %는 입력 품질 점수**이며 검증된 도착 적중 확률이 아닙니다. GPS 동의가 없거나 갱신이 5분을 넘으면 위치정보는 계산에 사용하지 않습니다.
- ETA 신뢰 점수 65 미만·오래된 예측 등에서는 선작업을 보류합니다. 현재 필수 작업·대기 트럭과 다음 작업까지의 여유시간도 검사합니다.
- 후보별 횟수는 같은 60분 미래 시나리오의 평균입니다. **총 추가 이동 = 재취급 + 선작업**이며 최초 적치와 본선 인출은 제외합니다. 전체 실험 결과는 완료된 이동만 집계합니다.
- 효과 분석의 자동 정책 비교와 현재 수동 시연은 별도의 실행입니다. 사용자가 ETA 입력이나 선호모델을 바꿔도 자동 비교를 현장 실측처럼 바꾸지 않습니다.
- 선박 일정 변경 시 아직 동결되지 않은 인출 예정시각을 편차만큼 옮기는 것은 데모 가정입니다. 실행 중·5분 내 예정 작업은 유지합니다. 선석 일정만으로 개별 선적 순서를 알 수 있다는 가정은 하지 않습니다.
- 선호모델은 **실제 데모 선택 기록의 쌍별 로지스틱 학습**입니다. 딥러닝 운영모델이 아닙니다. 물리 제약을 통과한 후보 중 기본 비용 차이가 5% 또는 60점 이내인 후보에만, 학습한 상황·화물 유형에서 적용합니다. 따라서 안전조건이나 명백한 비용 우위를 덮어쓰지 않으며 추천 순위가 유지될 수 있습니다.
- 승인·기사 확인·학습 버전은 `runtime/demo.sqlite3`에 저장합니다. 학습에는 현재 브라우저 세션의 기록만 사용합니다. 기록과 안내는 JSON/CSV로 다운로드 가능합니다. 클라우드 임시 디스크는 영구 저장소가 아닙니다.
